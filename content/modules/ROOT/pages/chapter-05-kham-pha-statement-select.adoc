= Tìm hiểu statement `SELECT`

Như đã thấy ở chương trước, chúng ta có thể sử dụng statement `SELECT` để lọc dữ liệu bằng điều kiện so sánh bằng. Tương tự, chúng ta có thể lọc các row theo điều kiện `>` hoặc `<`, như trong ví dụ sau:

[source,console,role="transcript"]
....
forumdb=> select * from categories where pk > 2;
    pk |         title            |                 description
----+-----------------------+---------------------------------
     3 | Programming Languages | All about programming languages
   (1 row)
....

.SQL
[source,sql]
....
SELECT *
FROM categories
WHERE pk > 2;
....

.Output
[source,output]
....
    pk |         title            |                 description
----+-----------------------+---------------------------------
     3 | Programming Languages | All about programming languages
   (1 row)
....


Query trên trả về tất cả các row có `pk > 2`.

Một điều kiện khác có thể dùng trong statement `SELECT` là điều kiện LIKE. Hãy xem ví dụ tiếp theo.
