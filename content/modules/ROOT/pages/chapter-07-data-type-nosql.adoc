= Data type NoSQL

Trong phần này, chúng ta sẽ tìm hiểu các data type NoSQL hiện có trong PostgreSQL. Vì cuốn sách không tập trung riêng vào NoSQL, chúng ta chỉ xem qua chúng ở mức khái quát.
PostgreSQL hỗ trợ các data type NoSQL sau:

* hstore
* xml
* json/jsonb

Tiếp theo, chúng ta sẽ tìm hiểu về hstore và JSON.

== Data type hstore

`hstore` là data type NoSQL đầu tiên được triển khai trong PostgreSQL. Data type này dùng để lưu các cặp key-value trong một giá trị duy nhất. Trước khi làm việc với data type `hstore`, chúng ta cần bật extension `hstore` trên server:

[source,console,role="transcript"]
....
forumdb=> create extension hstore ;
CREATE EXTENSION
....

.SQL
[source,sql]
....
CREATE extension hstore;
....

.Output
[source,output]
....
CREATE EXTENSION
....


Hãy xem cách sử dụng data type `hstore` qua một ví dụ. Giả sử chúng ta muốn hiển thị tất cả post kèm username và category tương ứng:

[source,console,role="transcript"]
....
forumdb=> select p.pk,p.title,u.username,c.title as category
from posts p
inner join users u on p.author=u.pk
left join categories c on p.category=c.pk
order by 1;

category | Database
-[ RECORD 2 ]--------------------------
pk         | 6

category | Database
-[ RECORD 3 ]--------------------------
pk         | 7
title      | A view of   Data types in C++
username | enrico_pirozzi
category | Programming Languages
....

[source,sql]
....
SELECT
    p.pk,
    p.title,
    u.username,
    c.title AS category
FROM posts p inner JOIN users u ON p.author = u.pk left JOIN categories c ON p.category = c.pk
ORDER BY 1;
....

Nếu làm được như vậy, chúng ta sẽ không còn cần join ba table lớn này với nhau. Trong trường hợp đó, `hstore` có thể giúp chúng ta:

[source,console,role="transcript"]
....
forumdb=> select p.pk,p.title,hstore(ARRAY['username',u.
username,'category',c.title]) as options
from posts p
inner join users u on p.author=u.pk
left join categories c on p.category=c.pk
order by 1;

-[ RECORD 2 ]--------------------------

-[ RECORD 3 ]--------------------------

pirozzi"

[source,sql]

SELECT
    p.pk,
    p.title,

FROM posts p inner JOIN users u ON p.author = u.pk left JOIN categories c ON p.category = c.pk
ORDER BY 1;
....

Như đã nói ở đầu phần này, NoSQL không phải là chủ đề của cuốn sách, nhưng vẫn đáng để xem qua ở mức khái quát. Để biết thêm thông tin về data type `hstore`, hãy tham khảo documentation chính thức tại https://www.postgresql.org/docs/current/hstore.html.

== Data type JSON

Trong phần này, chúng ta sẽ xem nhanh data type JSON. JSON là viết tắt của JavaScript Object Notation. JSON là một format theo chuẩn mở, được tạo thành từ các cặp key-value. PostgreSQL hỗ trợ JSON như một native data type. Nó cung cấp nhiều function và operator để thao tác với dữ liệu JSON. Ngoài data type JSON, PostgreSQL còn hỗ trợ data type JSONB. JSON được biểu diễn nội bộ dưới dạng text, còn JSONB được biểu diễn dưới dạng binary và có thể được index. Hãy xem cách sử dụng data type JSON/JSONB qua một ví dụ.

Giả sử chúng ta muốn hiển thị tất cả post và tag hiện có trong database `forumdb`. Theo cách tiếp cận SQL relational truyền thống, chúng ta sẽ viết như sau:

(5 rows)

Những gì vừa viết chỉ là một phần rất nhỏ trong những gì có thể làm với NoSQL data model. JSON được dùng rộng rãi khi làm việc với các table lớn và khi cần một data structure giúp giảm số lần join trong quá trình tìm kiếm. Thảo luận chi tiết về thế giới NoSQL nằm ngoài phạm vi cuốn sách này, nhưng qua ví dụ này, chúng ta muốn minh họa ngắn gọn sức mạnh của PostgreSQL khi làm việc với unstructured data. Để biết thêm thông tin, hãy xem documentation chính thức tại https://www.postgresql.org/docs/current/functions-json.html.

Sau khi hiểu data type là gì và PostgreSQL hỗ trợ những data type nào, phần tiếp theo sẽ trình bày cách dùng data type bên trong function.
