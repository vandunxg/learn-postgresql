= Yêu cầu kỹ thuật

Bạn cần nắm được các nội dung sau:

* Cách thực thi query trên database
* Cách thực thi các statement thuộc *data description language (DDL)*

Các ví dụ trong chương này có thể chạy trên image `chapter_13` trong GitHub repository của cuốn sách: https://github.com/PacktPublishing/Learn-PostgreSQL-Second-Edition. Để biết cách cài đặt và sử dụng các Docker image có sẵn cho cuốn sách này, hãy xem hướng dẫn trong Chương 1, Introduction to PostgreSQL.
