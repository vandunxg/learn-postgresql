= Sử dụng `distinct`

Bây giờ, chúng ta sẽ tìm hiểu một loại query khác: query `distinct`. Tuy nhiên, trước hết cần giới thiệu một function khác rất hữu ích cho DBA, đó là function `coalesce`. Khi nhận từ hai đối số trở lên, function `coalesce` trả về giá trị đầu tiên khác `NULL`.

Ví dụ, hãy thử function `coalesce` với giá trị kiểm thử sau đây:

[source,console,role="transcript"]
....
forumdb=> select coalesce(NULL,'test');
   coalesce
----------
   test
(1 row)
....

.SQL
[source,sql]
....
SELECT coalesce(NULL, 'test');
....

.Output
[source,output]
....
   coalesce
----------
   test
(1 row)
....


Trong query trên, function `coalesce` trả về `test` vì đối số đầu tiên là `NULL`, còn đối số thứ hai không phải `NULL`.

Bây giờ, hãy thêm một category mới:

[source,console,role="transcript"]
....
forumdb=> insert into categories (title) values ('New Category');
INSERT 0 1
....

.SQL
[source,sql]
....
INSERT INTO categories (title)
VALUES ('New Category');
....

.Output
[source,output]
....
INSERT 0 1
....


Tiếp theo, hãy thực hiện query sau:

[source,console,role="transcript"]
....
forumdb=# \pset null (NULL)
Null display is "(NULL)".
....

.SQL
[source,sql]
....
\pset NULL (NULL)
....

.Output
[source,output]
....
Null display is "(NULL)".
....


[source,console,role="transcript"]
....
forumdb=> select pk,title,description from categories;
 pk |            title             |              description
 ----+-----------------------+----------------------------
  1 | Database                     | Database related discussions
  2 | Unix                         | Unix and Linux discussions
  3 | Programming Languages       | All about programming languages
  4 | New Category                | (NULL)
(4 rows)
....

.SQL
[source,sql]
....
SELECT
    pk,
    title,
    description
FROM categories;
....

.Output
[source,output]
....
 pk |            title             |              description
 ----+-----------------------+----------------------------
  1 | Database                     | Database related discussions
  2 | Unix                         | Unix and Linux discussions
  3 | Programming Languages       | All about programming languages
  4 | New Category                | (NULL)
(4 rows)
....


Trong ví dụ trên, column `description` có giá trị `NULL` trong row có title là `New Category`.

Bây giờ, hãy thử dùng function `coalesce` để hiển thị giá trị `No Description` thay cho `NULL`.

[source,console,role="transcript"]
....
forumdb=> select pk,title,coalesce(description,'No description') from
categories;
 pk |            title             |               coalesce
 ----+-----------------------+----------------------------
  1 | Database                     | Database related discussions
  2 | Unix                         | Unix and Linux discussions
  3 | Programming Languages       | All about programming languages
  4 | New Category                | No description
(4 rows)
....

.SQL
[source,sql]
....
SELECT
    pk,
    title,
    coalesce(description, 'No description')
FROM categories;
....

.Output
[source,output]
....
 pk |            title             |               coalesce
 ----+-----------------------+----------------------------
  1 | Database                     | Database related discussions
  2 | Unix                         | Unix and Linux discussions
  3 | Programming Languages       | All about programming languages
  4 | New Category                | No description
(4 rows)
....


Trong đoạn code trên, function `coalesce` chuyển mọi giá trị `NULL` thành chuỗi `No description`. Một điểm khác khiến việc dùng function `coalesce` kém thân thiện với người dùng là tên column được gán khi gọi function không phải là tên chúng ta mong muốn. Trong trường hợp này, column thứ hai trong result set có tên `coalesce`, trong khi chúng ta muốn một tên dễ đọc hơn; khi làm việc trong một nhóm, tên dễ đọc được ưu tiên.

Trong PostgreSQL, có thể gán alias cho bất kỳ column nào trong query. Ví dụ, chúng ta có thể gán alias cho column `coalesce` như sau:

[source,console,role="transcript"]
....
forumdb=> select pk,title,coalesce(description,'No description') as
description from categories;
 pk |            title             |              description
 ----+-----------------------+---------------------------------
  1 | Database                     | Database related discussions
  2 | Unix                         | Unix and Linux discussions
  3 | Programming Languages       | All about programming languages
  4 | New Category                | No description
(4 rows)
....

.SQL
[source,sql]
....
SELECT
    pk,
    title,
    coalesce(description, 'No description') AS description
FROM categories;
....

.Output
[source,output]
....
 pk |            title             |              description
 ----+-----------------------+---------------------------------
  1 | Database                     | Database related discussions
  2 | Unix                         | Unix and Linux discussions
  3 | Programming Languages       | All about programming languages
  4 | New Category                | No description
(4 rows)
....


Khi đó, result set có column `description` thay cho column `coalesce`.

Nếu muốn dùng alias có khoảng trắng hoặc chữ hoa, phải đặt alias trong dấu ngoặc kép `""`, như trong ví dụ sau:

[source,console,role="transcript"]
....
forumdb=> select pk,title,coalesce(description,'No description') as
"Description" from categories;
 pk |           title           |              Description
----+---------------------------+---------------------------------
  1 | Database                  | Database related discussions
  2 | Unix                      | Unix and Linux discussions
  3 | Programming Languages    | All about programming languages
  4 | New Category             | No description
(4 rows)
....

.SQL
[source,sql]
....
SELECT
    pk,
    title,
    coalesce(description, 'No description') AS "Description"
FROM categories;
....

.Output
[source,output]
....
 pk |           title           |              Description
----+---------------------------+---------------------------------
  1 | Database                  | Database related discussions
  2 | Unix                      | Unix and Linux discussions
  3 | Programming Languages    | All about programming languages
  4 | New Category             | No description
(4 rows)
....


Result set không có alias là `Description` (chữ hoa), mà lại có alias là `description` (chữ thường), dường như không đúng. Bây giờ, hãy insert một row khác như sau:

[source,console,role="transcript"]
....
forumdb=> insert into categories (title,description) values
('Database','PostgreSQL');
INSERT 0 1
....

.SQL
[source,sql]
....
INSERT INTO categories (title, description)
VALUES ('Database', 'PostgreSQL');
....

.Output
[source,output]
....
INSERT 0 1
....


Tiếp theo, hãy thực hiện query này:

[source,console,role="transcript"]
....
forumdb=> select title from categories order by title;
            title
-----------------------
 Database
 Database
 New Category
 Programming Languages
 Unix
(5 rows)
....

.SQL
[source,sql]
....
SELECT title
FROM categories
ORDER BY title;
....

.Output
[source,output]
....
            title
-----------------------
 Database
 Database
 New Category
 Programming Languages
 Unix
(5 rows)
....


Như có thể thấy trong query trên, có 2 row có cùng giá trị `Database`; nếu muốn chỉ hiển thị các giá trị không trùng lặp, chúng ta phải dùng clause `DISTINCT`:

[source,console,role="transcript"]
....
forumdb=> select distinct title from categories order by title;
            title
-----------------------
 Database
 New Category
 Programming Languages
 Unix
(4 rows)
....

.SQL
[source,sql]
....
SELECT DISTINCT title
FROM categories
ORDER BY title;
....

.Output
[source,output]
....
            title
-----------------------
 Database
 New Category
 Programming Languages
 Unix
(4 rows)
....


Trong query trên, chúng ta đã sử dụng statement `select distinct`. Statement `select distinct` chỉ trả về các giá trị không trùng lặp. Với các table lớn, việc dùng `distinct` có thể khiến PostgreSQL phải sort dữ liệu. Vì vậy, query dùng `distinct` có thể chậm hơn khi số lượng row tăng lên.
