= Kiểm tra kiến thức

* Có cần cấu hình file `pg_hba.conf` trước khi bắt đầu physical replication không?

  Có.

  Xem phần *Quản lý streaming replication* để biết thêm chi tiết.

* PostgreSQL có hỗ trợ asynchronous replication không?

  Có, đây là configuration mặc định.

  Xem phần *Quản lý streaming replication* để biết thêm chi tiết.

* PostgreSQL có hỗ trợ synchronous replication không?

  Có, bằng cách chỉnh sửa `postgresql.conf` trên primary server và `postgresql.auto.conf` trên replica server.

  Xem phần *Synchronous replication* để biết thêm chi tiết.

* PostgreSQL có hỗ trợ cascading replication không?

  Có, bằng cách dùng command `pg_basebackup` để lấy data từ replica server.

  Xem phần *Cascading replication* để biết thêm chi tiết.

* Có thể promote một replica node thành primary node không?

  Có, bằng cách dùng command `pg_ctl promote`.

  Xem phần *Promote replica server thành primary* để biết thêm chi tiết.
