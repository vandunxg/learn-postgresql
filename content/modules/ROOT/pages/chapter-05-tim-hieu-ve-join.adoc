== Sử dụng RIGHT JOIN

RIGHT JOIN là phiên bản đối xứng của LEFT JOIN, vì vậy table A LEFT JOIN table B và table B RIGHT JOIN table A cho cùng một kết quả. Ví dụ, ta có thể viết:

[source,sql]
....
SELECT
    c.*,
    p.category
FROM categories c left JOIN posts p ON p.category = c. pk;
....

hoặc nếu viết:

[source,sql]
....
SELECT
    c.*,
    p.category,
    p.title
FROM posts p right JOIN categories c ON c.pk = p.category;

== Sử dụng LATERAL JOIN

LATERAL JOIN là một kiểu JOIN trong SQL cho phép kết hợp một table với một subquery, trong đó subquery được thực thi cho từng row của table chính. Subquery được thực thi trước khi các row được kết hợp, và kết quả của subquery được dùng để kết hợp các row. Với kiểu JOIN này, chúng ta có thể dùng thông tin từ một table để lọc hoặc xử lý dữ liệu từ table khác.

Hãy thêm một column có tên `likes` vào table `posts`, rồi chèn một số dữ liệu vào column này:

[source,console,role="transcript"]
....
forumdb=> alter table posts add likes integer default 0;
ALTER TABLE
forumdb=> update posts set likes = 3 where title like 'Indexing%';
UPDATE 2
....

.SQL
[source,sql]
....
ALTER TABLE posts ADD likes integer DEFAULT 0;
UPDATE posts
SET
    likes = 3
WHERE title like 'Indexing%';
....

.Output
[source,output]
....
ALTER TABLE
UPDATE 2
....


Tình trạng hiện tại:

[source,console,role="transcript"]
....
forumdb=> select title,likes from posts order by likes ;
          title          | likes
---------------------+-------
 Data types in C++     |      0
 Indexing PostgreSQL |        3
 Indexing Mysql        |      3
(3 rows)
....

.SQL
[source,sql]
....
SELECT
    title,
    likes
FROM posts
ORDER BY likes;
....

.Output
[source,output]
....
          title          | likes
---------------------+-------
 Data types in C++     |      0
 Indexing PostgreSQL |        3
 Indexing Mysql        |      3
(3 rows)
....


Giả sử muốn tìm tất cả user có post với số lượt like lớn hơn 2. Query tương ứng là:

[source,console,role="transcript"]
....
forumdb=> select u.* from users u where exists (select 1 from posts p
where u.pk=p.author and likes > 2 ) ;
 pk |     username   | gecos |           email
----+--------------+-------+---------------------
  1 | luca_ferrari |          | luca@pgtraining.com
(1 row)
....

.SQL
[source,sql]
....
SELECT u.*
FROM users u
WHERE EXISTS (SELECT 1 FROM posts p WHERE u.pk = p.author AND likes > 2);
....

.Output
[source,output]
....
 pk |     username   | gecos |           email
----+--------------+-------+---------------------
  1 | luca_ferrari |          | luca@pgtraining.com
(1 row)
....


Giả sử chúng ta cũng muốn lấy giá trị của column `likes`. Một cách đơn giản là dùng LATERAL JOIN:

[source,console,role="transcript"]
....
forumdb=> select u.username,q.* from users u join lateral (select author,
title,likes from posts p where u.pk=p.author and likes > 2 ) as q on true;
   username     | author |          title            | likes
--------------+--------+---------------------+-------
 luca_ferrari |        1 | Indexing PostgreSQL |           3
 luca_ferrari |        1 | Indexing Mysql            |     3
(2 rows)
....

.SQL
[source,sql]
....
SELECT
    u.username,
    q.*
FROM users u JOIN lateral (SELECT author, title, likes FROM posts p WHERE u.pk = p.author AND likes > 2) AS q ON TRUE;
....

.Output
[source,output]
....
   username     | author |          title            | likes
--------------+--------+---------------------+-------
 luca_ferrari |        1 | Indexing PostgreSQL |           3
 luca_ferrari |        1 | Indexing Mysql            |     3
(2 rows)
....


Query này rất giống query `EXISTS`, ngoại trừ việc query chính có thể lấy các giá trị từ subquery và sử dụng chúng.
