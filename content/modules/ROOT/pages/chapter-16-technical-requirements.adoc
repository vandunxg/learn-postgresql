= Yêu cầu kỹ thuật

Bạn cần biết các nội dung sau để hoàn thành chương này:

* Cách làm việc với configuration file trong thư mục `PGDATA`
* Cách kết nối tới cluster với tư cách database administrator
* Cách thực thi SQL statement trên system catalog

Các ví dụ trong chương này có thể chạy trên Docker image `chapter_16`, có thể tìm thấy trong GitHub repository của cuốn sách: https://github.com/PacktPublishing/Learn-PostgreSQL-Second-Edition.
