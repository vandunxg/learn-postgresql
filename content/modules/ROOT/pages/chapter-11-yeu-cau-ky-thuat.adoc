= Yêu cầu kỹ thuật

Để tiếp tục, bạn cần nắm được những nội dung sau:

* Cách chạy SQL statement bằng `psql`
* Cách kết nối tới cluster và một database
* Cách kiểm tra và thay đổi configuration của cluster

Các ví dụ trong chương này có sẵn trong code repository của cuốn sách và có thể chạy trên standalone Docker image có trong GitHub repository của cuốn sách: https://github.com/PacktPublishing/Learn-PostgreSQL-Second-Edition.
