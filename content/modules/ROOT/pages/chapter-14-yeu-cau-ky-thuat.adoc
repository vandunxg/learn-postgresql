= Yêu cầu kỹ thuật

Bạn cần nắm được các nội dung sau:

* Cách quản lý configuration của PostgreSQL
* Cách start, restart và monitor PostgreSQL, cũng như cách tương tác với các file trong `PGDATA`

Các ví dụ trong chương này có thể chạy trên Docker image `chapter_14`, có thể tìm thấy trong GitHub repository của cuốn sách: https://github.com/PacktPublishing/Learn-PostgreSQL-Second-Edition. Để biết cách cài đặt và sử dụng các Docker image có sẵn cho cuốn sách này, hãy tham khảo hướng dẫn trong Chương 1, *Giới thiệu về PostgreSQL*.
