= Tóm tắt

PostgreSQL có thể xử lý nhiều database trong một cluster duy nhất; disk storage của cluster nằm trong một directory duy nhất có tên `PGDATA`. Cluster chạy nhiều process khác nhau; một process đặc biệt, gọi là `postmaster`, chịu trách nhiệm spawn các process khác, mỗi process phục vụ một client connection, đồng thời theo dõi trạng thái của các maintenance process.

Configuration của cluster được quản lý thông qua các configuration file dạng text, trong đó file chính là `postgresql.conf`. Các rule trong text file `pg_hba.conf` dùng để lọc các connection từ user đi vào cluster.

Bạn có thể quản lý trạng thái của cluster bằng tool `pg_ctl` hoặc, tùy operating system, bằng các chương trình khác được cung cấp, chẳng hạn `service` hoặc `systemctl`.

Chương này đã trình bày những thông tin cần thiết để bạn không chỉ cài đặt PostgreSQL mà còn biết cách thường xuyên khởi động, dừng và tích hợp PostgreSQL với operating system, cũng như kết nối đến cluster.

Trong chương tiếp theo, bạn sẽ học cách quản lý user và connection.
