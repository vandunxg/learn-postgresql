= Yêu cầu kỹ thuật

Kiến thức cần có cho chương này gồm:

* Cách cài đặt các binary package trên máy Unix của bạn
* Các thuật ngữ PostgreSQL cơ bản (từ chương trước)
* Cách sử dụng Unix command line ở mức cơ bản
* Các SQL statement cơ bản được đề cập trong chương này, chẳng hạn như `SELECT`

Các ví dụ trong chương này có thể chạy trong Docker image độc lập. Bạn có thể tìm thấy image này trong GitHub repository của cuốn sách: https://github.com/PacktPublishing/Learn-PostgreSQL-Second-Edition. Để biết cách cài đặt và sử dụng các Docker image dành cho cuốn sách, hãy tham khảo hướng dẫn trong Chương 1, Giới thiệu về PostgreSQL.
