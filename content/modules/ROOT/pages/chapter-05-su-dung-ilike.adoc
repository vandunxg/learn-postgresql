= Sử dụng `ilike`

Trong PostgreSQL, bạn có thể dùng operator `like` để thực hiện query `ilike` mà không phân biệt chữ hoa chữ thường.

Khi đó, query sẽ như sau:

[source,console,role="transcript"]
....
forumdb=> select * from categories where description ilike '%DISCUSS%';
   pk |   title   |              description
----+----------+------------------------------
    1 | Database | Database related discussions
    2 | Unix      | Unix and Linux discussions
(2 rows)
....

.SQL
[source,sql]
....
SELECT *
FROM categories
WHERE description ilike '%DISCUSS%';
....

.Output
[source,output]
....
   pk |   title   |              description
----+----------+------------------------------
    1 | Database | Database related discussions
    2 | Unix      | Unix and Linux discussions
(2 rows)
....


Đây là cách PostgreSQL giải quyết vấn đề với query `like` không phân biệt chữ hoa chữ thường mà chúng ta đã gặp trước đó.
