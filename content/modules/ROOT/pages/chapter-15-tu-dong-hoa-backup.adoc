= Tự động hóa backup

Bằng cách kết hợp `pg_dump` và `pg_dumpall`, bạn có thể dễ dàng tự động hóa backup, chẳng hạn chạy mỗi đêm hoặc mỗi ngày vào thời điểm database system ít được sử dụng. Tùy vào operating system đang dùng, bạn có thể lên lịch để các backup này được tạo và tự động rotate.

Ví dụ, trên Unix, bạn có thể lên lịch `pg_dump` thông qua `cron(1)` như sau:

[source,console,role="transcript"]
....
$ crontab -e
....

.Command
[source,bash]
....
crontab -e
....


Sau đó, thêm dòng sau:

[source,text]
....
30 23 * * * pg_dump -Fc -f /backup/forumdb.backup -U forum forumdb
....

Dòng này tạo một full backup ở custom format mỗi ngày lúc 23:30. Tuy nhiên, cách tiếp cận này có một vài nhược điểm, chẳng hạn như việc quản lý các backup đã tồn tại, xử lý các database mới được thêm vào và thêm một dòng khác vào `crontab`, v.v.

Nhờ tính linh hoạt của PostgreSQL và catalog của nó, không khó để phát triển một wrapper script có thể xử lý backup cho mọi database. Để bắt đầu, script sau thực hiện full backup cho mọi database ngoại trừ `template0`:

[source,console,role="transcript"]
....
#!/bin/sh

BACKUP_ROOT=/backup

for database in $( psql -U postgres -A -t -c "SELECT datname FROM pg_database WHERE datname <> 'template0'" postgres )
do
     backup_dir=$BACKUP_ROOT/$database/$(date +'%Y-%m-%d')
     if [ -d $backup_dir ]; then
          echo "Skipping backup $database, already done today!"
          continue
     fi

     mkdir -p $backup_dir
     pg_dump -U postgres -Fd -f $backup_dir $database
     echo "Backup $database into $backup_dir done!"
done
....

.Command
[source,bash]
....
!/bin/sh
....

.Output
[source,output]
....
BACKUP_ROOT=/backup

for database in $( psql -U postgres -A -t -c "SELECT datname FROM pg_database WHERE datname <> 'template0'" postgres )
do
     backup_dir=$BACKUP_ROOT/$database/$(date +'%Y-%m-%d')
     if [ -d $backup_dir ]; then
          echo "Skipping backup $database, already done today!"
          continue
     fi

     mkdir -p $backup_dir
     pg_dump -U postgres -Fd -f $backup_dir $database
     echo "Backup $database into $backup_dir done!"
done
....


Ý tưởng khá đơn giản: script query PostgreSQL catalog `pg_database` để lấy mọi database mà database cluster phục vụ; với mỗi database, script tìm một directory riêng được đặt tên theo database và chứa một directory được đặt tên theo ngày hiện tại. Nếu directory đó tồn tại, backup đã được thực hiện, nên script chỉ cần chuyển sang database tiếp theo. Nếu không, backup có thể được thực hiện. Ví dụ, một ngày hệ thống sẽ backup database `forumdb` vào directory `/backup/forumdb/2023-07-19`, ngày hôm sau vào `/backup/forumdb/2023-07-20`, rồi tiếp tục như vậy. Nhờ đó, bạn có thể thêm script trên vào `crontab` mà không cần bận tâm đến việc thêm các dòng mới cho database mới hoặc xóa các dòng tương ứng với database đã bị xóa:

[source,text]
....
30 23 * * * my_backup_script.sh
....

Dĩ nhiên, script trên chưa phải là một hệ thống backup phức tạp; nó chỉ là điểm bắt đầu nếu bạn cần một giải pháp nhanh và linh hoạt để thực hiện automated logical backup bằng các tool mà PostgreSQL cluster và operating system cung cấp. Như đã nói, nhiều operating system đã tính đến việc backup một PostgreSQL cluster và cung cấp sẵn các script để giúp bạn giải quyết vấn đề này. Một ví dụ rất tốt cho loại script này là `502.pgsql`, được cung cấp trong package PostgreSQL của FreeBSD.
