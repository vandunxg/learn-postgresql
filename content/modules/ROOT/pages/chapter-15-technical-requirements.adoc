= Yêu cầu kỹ thuật

Bạn cần nắm được những nội dung sau để hoàn thành chương này:

* Cách làm việc với command-line tool
* Cách kiểm tra filesystem và directory `PGDATA`

Các ví dụ trong chương này có thể chạy trên Docker image `chapter_15`, có trong GitHub repository của cuốn sách: https://github.com/PacktPublishing/Learn-PostgreSQL-Second-Edition. Để biết hướng dẫn cài đặt và sử dụng các Docker image có trong cuốn sách, hãy tham khảo phần hướng dẫn trong Chương 1, *Giới thiệu về PostgreSQL*.
