= Tổng kết

Trong chương này, chúng ta đã giới thiệu về lập trình phía server. Chủ đề này rộng đến mức có hẳn những cuốn sách viết riêng về nó. Chúng ta đã cố gắng giúp bạn hiểu rõ hơn các khái niệm chính của lập trình phía server. Chúng ta đã tìm hiểu các data type chính do PostgreSQL quản lý, rồi xem cách tạo data type mới bằng cách sử dụng composite data type. Chúng ta cũng đề cập đến SQL function và polymorphic function, rồi cuối cùng cung cấp một số thông tin về ngôn ngữ PL/pgSQL.

Trong chương tiếp theo, chúng ta sẽ sử dụng các khái niệm này để giới thiệu cách quản lý event trong PostgreSQL. Chúng ta sẽ tìm hiểu cách quản lý event bằng trigger và các function gắn với chúng.
